# Changelog

## 1.0.1 — 2026-11-18

- Add Anthropic Messages and Google Gemini adapters, plus DeepSeek, Groq, Mistral, xAI, OpenRouter, Together AI, Fireworks AI, Cerebras, and Ollama presets.
- Add custom OpenAI-compatible endpoints, provider-specific API keys, and configurable chat response formats with shared evidence validation and privacy limits.
- Recognize nwidart modules, local packages, domain layouts, and Apiato containers; expand Laravel categories and include affected module counts in reports.
- Add configurable module roots and category/review rules shared by reports and optional bounded AI excerpts.
- Document provider setup, migration of published configuration, and provider-specific retention limitations.
- Enable the fileinfo extension for Windows compatibility CI.
- Keep checkout line endings consistent for style checks on Windows and Linux.
- Add the auto-discovered `wtf:happened` Laravel command.
- Analyze bounded local Git history with application-subtree scope and deterministic Laravel categories.
- Add human-readable and versioned JSON reports, review suggestions, and Git-only humor.
- Add optional OpenAI interpretation with persistent opt-in and separately authorized bounded PHP excerpts.
- Add privacy filtering, mocked AI tests, temporary Git fixtures, and compatibility CI.

First tagged stable release. Earlier development snapshots were available on Packagist as `dev-main`.
